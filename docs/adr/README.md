# Architecture Decision Records

Este directorio contiene los ADRs (Architecture Decision Records) del proyecto TaskMaster-TS.

## Formato

Cada ADR sigue el formato de [Michael Nygard](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions):

- **Título**: corto, en pasado ("Elegimos X para Y")
- **Contexto**: situación actual que motiva la decisión
- **Decisión**: la alternativa elegida
- **Consecuencias positivas**: lo que gana el equipo
- **Consecuencias negativas**: lo que pierde o acepta el equipo (ser honesto)
- **Alternativas consideradas**: las otras opciones y por qué se descartaron
