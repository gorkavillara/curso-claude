NOTA PARA GRABAR:
- La línea clave del error es: "ERROR Configuration error: DATABASE_URL is not defined"

- Verificación: `docker compose config` muestra las variables resueltas
- Fix: renombrar DB_URL a DATABASE_URL en .env, o usar DB_URL en compose.yml
