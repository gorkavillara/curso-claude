NOTA PARA GRABAR:
Causa raíz: el job `test` usa `npm ci --production`, que excluye devDependencies.
`@types/jest` está en devDependencies → no se instala → los tests no pueden importarlo.

Evidencia clave: línea 67 del log → "npm ci --production"
                 línea 84 del log → "Cannot find module '@types/jest/globals'"

Fix: cambiar `npm ci --production` a `npm ci` en el job `test` del ci.yml
     (el build stage puede seguir usando --omit=dev o --production)

Verificación: relanzar el workflow tras el fix y comprobar que los 3 tests pasan.
