# Open Web Application Security Project
## OWASP Top 10 2021

1. Broken Access Control — Control de acceso roto (autorización deficiente)
2. Cryptographic Failures — Fallos criptográficos (exposición de datos sensibles)
3. Injection — Inyección (SQL, NoSQL, OS, etc.)
4. Insecure Design — Diseño inseguro (falta de validación, sin límites)
5. Security Misconfiguration — Configuración incorrecta de seguridad
6. Vulnerable and Outdated Components — Componentes vulnerables o desactualizados
7. Identification and Authentication Failures — Fallos en autenticación e identificación
8. Software and Data Integrity Failures — Fallos en integridad de software y datos
9. Logging and Monitoring Failures — Fallos en logging y monitoreo
10. Server-Side Request Forgery (SSRF) — Falsificación de solicitud del lado del servidor
