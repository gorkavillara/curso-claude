# EV-105 — `created_at` se devuelve sin formato ISO

**Estado:** To Do · **Prioridad:** Baja · **Componente:** `backend/src/models/task.ts`

## Descripción

SQLite guarda `created_at` con `datetime('now')` → string tipo `2026-05-15 10:05:01`
(sin `T`, sin zona). El frontend espera ISO 8601 (`2026-05-15T10:05:01Z`) y la fecha se
muestra mal en algunos navegadores.

## Criterio de aceptación

- `rowToTask` normaliza `created_at` a ISO 8601 UTC.
- No cambia el almacenamiento, solo la salida del modelo.
