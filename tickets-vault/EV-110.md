# EV-110 — Tests de integración no cubren errores 4xx

**Estado:** To Do · **Prioridad:** Media · **Componente:** `tests/`

## Descripción

La suite de integración solo prueba caminos felices (`201`, `200`). No hay tests para
`400` (validación), `404` (no encontrado) ni `500`. Los bugs de [[EV-101]], [[EV-103]] y
[[EV-106]] habrían salido con tests de error.

## Criterio de aceptación

- Añadir tests de integración para `400`, `404`.
- Cubrir al menos: prioridad inválida (EV-101), status inválido (EV-103), delete
  inexistente (EV-106).
- La suite sigue en verde.

## Notas

Depende de que [[EV-101]], [[EV-103]] y [[EV-106]] estén cerrados (si no, los tests
fallarían a propósito).
