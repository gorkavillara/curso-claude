# EV-106 — `DELETE /api/tasks/:id` no comprueba existencia

**Estado:** To Do · **Prioridad:** Alta · **Componente:** `backend/src/routes`

## Descripción

`DELETE /api/tasks/:id` devuelve siempre `200` aunque el `id` no exista. El cliente cree
que borró algo cuando no había nada. Debería distinguir borrado real de no-encontrado.

## Pasos para reproducir

1. `DELETE /api/tasks/99999` (id inexistente).
2. Respuesta `200 OK`.
3. No se borró nada, pero el frontend muestra "Tarea eliminada".

## Criterio de aceptación

- Si el id existe y se borra → `204`.
- Si el id no existe → `404`.
- La comprobación de existencia, en el modelo.

## Notas

Mismo patrón de "no comprueba estado real" que [[EV-103]] pero en escritura.
