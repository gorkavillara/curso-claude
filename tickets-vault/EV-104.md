# EV-104 — Falta paginación en `GET /api/tasks`

**Estado:** To Do · **Prioridad:** Media · **Componente:** `backend/src/routes`

## Descripción

`GET /api/tasks` devuelve el listado completo sin límite. Con miles de tareas la
respuesta pesa demasiado y el frontend se ralentiza.

## Criterio de aceptación

- Soportar `?limit` (default 50, máximo 200) y `?offset` (default 0).
- Devolver metadatos: `{ total, limit, offset, items }`.
- `limit`/`offset` no numéricos → `400`.

## Notas

Toca el mismo handler que [[EV-101]] y [[EV-103]]; coordinar para no pisarse.
