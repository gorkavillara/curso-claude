# EV-109 — Falta endpoint de completar tareas en lote

**Estado:** Backlog · **Prioridad:** Baja · **Componente:** `backend/src/routes`

## Descripción

No hay forma de marcar varias tareas como completadas en una sola petición. El frontend
hace N llamadas `PATCH`. Sería útil un `POST /api/tasks/bulk-complete` con una lista de ids.

## Criterio de aceptación

- `POST /api/tasks/bulk-complete` con body `{ "ids": [1,2,3] }`.
- Devuelve cuántas se actualizaron y cuáles no existían.
- Operación atómica (transacción).

## Notas

Nice-to-have. No bloquea a nadie. Revisar tras cerrar el sprint actual.
