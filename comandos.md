| Comando | Para qué | Cuándo |
|---|---|---|
| `claude` | Sesión nueva interactiva | Empezar algo nuevo |
| `claude -c` (`--continue`) | Retoma la **última** sesión de este repo | "Sigo donde lo dejé ayer" |
| `claude --resume` | **Elegir** de una lista de sesiones pasadas | "¿Cuál era la del bug de SQLite?" |
| `claude -p "..."` | One-shot, sin REPL, escupe y sale | Scripts, pipes, automatización |
